**Abstract**
The Bayesian single-index model (BSIM) is a powerful and widely adopted semiparametric regression framework. It integrates interpretability and flexibility by projecting
predictors onto a single index while allowing for an arbitrary link function. Despite its
advantages, available tools for fitting BSIM in R have been limited. Existing implementations often support only limited prior specifications, and their differing interfaces complicate model comparison. To address these limitations, we developed BayesSIM, the first comprehensive R package for Bayesian estimation of single-index models. The package supports a wide range of link functions and prior specifications for the index vector, implemented through Markov chain Monte Carlo (MCMC) within the nimble framework. The package provides user-friendly functions for flexible prior specification, model estimation, convergence diagnostics, and prediction of new data. BayesSIM is designed to be accessible to both novice and advanced users and to offer a simple implementation relative to currently available packages. The functionality of the package is illustrated using simulated and real-world data.
